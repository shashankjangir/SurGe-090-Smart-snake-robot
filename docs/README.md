# Project documentation

I wrote these guides so someone can understand our project without reading the chat history. They describe the code and recorded hardware setup as of 3 November 2026.

1. [My project story](PROJECT.md): the idea, three generations and how we built the robot.
2. [Start here](START_HERE.md): install Python dependencies, configure login and open the dashboard.
3. [Hardware](hardware/README.md): parts, body, wiring and measured joint settings.
4. [Software](SOFTWARE.md): how the browser, host, radio and servos work together.
5. [Operating guide](operations/1_APP_USAGE_MANUAL.md): connection, commissioning and bench commands.
6. [Simulation](gen3/GEN3_SIMULATION.md): the model, routes and limits of its results.
7. [Current status](CURRENT_STATUS.md): work history, verification and remaining problems.
8. [Folder guide](REPOSITORY_LAYOUT.md): source locations and checks.

Specific references are the [controller guide](operations/CONTROLLER_UPGRADES.md), [serial/API reference](architecture/API_DOCUMENTATION.md), [OTA guide](operations/FIRMWARE_OTA.md) and [handoff](GEN3_HANDOFF.md).
